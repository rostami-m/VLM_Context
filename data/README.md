# Released numerical evidence and frozen protocols

`analysis/` contains compact per-example analysis inputs, including original generated answers and token scores where needed to recalculate predictions, paired query outcomes, and source hashes. `paper/` contains reference numerical summaries and prompt fixtures. `protocols/` contains exact query/support schedules, label assignments, fitting episodes, parameter targets, source dataset indices, scene blueprints and model snapshot fingerprints. No dataset images, model weights or private review documents are included.

`PROVENANCE.json` records the published file checksums and distinguishes original exports from derived parser updates. The analysis manifests and records preserve source hashes and settings. Operational machine paths, approval state and campaign bookkeeping were removed. Remaining archive-relative `raw_record` references in earlier reference summaries are source identifiers, not required filesystem paths. Random namespaces and disjoint-role definitions are retained because they affect the scientific protocol. Original score values are preserved; normalized generation fields are explicitly marked as derived. Gzip headers have deterministic timestamps.

The Q05 raw export contains 57,600 original answers and complete candidate token scores, which independently reproduce the 2,880 complete-panel metric rows. The native export contains all 6,480 family/replication outcomes; position controls contain 1,440 original outcomes. `core_cells` contains 249 reference aggregate cells; `core_seed_cells` contains their absolute per-replicate metrics, and `core_seed_contrasts` contains paired differences. Other `*_results` files retain reference family/task/policy summaries. `paper/prompts/` contains 44 source-bound native prompt fixtures. The regenerator reduces the released per-example inputs and performs the statistical resampling on CPU before rendering tables and figures. See [analysis coverage and commands](../docs/ANALYSIS.md).

Native strict-generation fields use the common normalized whole-label grammar. Separate `exact_format_*` fields preserve case/punctuation-sensitive compliance. Prompt fixtures preserve their source-record hash and identify the derived parser fields explicitly. The original source-record hashes and the hashes of these derived public artifacts serve different purposes.

The frozen protocol files distinguish task-specific Q05 training, Shapes-only core training, Q13 mixed natural/remap training, frozen native family probes, open-task transfer, interventions, and continual/controller schedules. These are distinct experiments and must not be interchanged. See the reproduction documents for executable entry points and image materialization commands.
